# Phase 17 design decision

Inspection: native InvestigationRunner snapshots whitelisted normalized EventRecords for the case entities, bounded by occurred/ingested time. Role tools enforce retrieval scope and provenance. validate_output requires all predicates supported, no missing evidence/contradictions or truncated snapshot before accepting COMPLETED. Hypotheses remain interpretations. coordinate waits for all required tasks; incomplete outcomes request human review, while all COMPLETED outcomes naturally schedule REQUEST_SUPERVISOR_REVIEW. SupervisorRunner rechecks stored references and current source predicates before accepting an advisory result. WorkQueue ownership/leases remain authoritative. The existing disposable database helper creates/migrates/drops only its own database. The runner excludes executable handlers and stops on unexpected tasks.
