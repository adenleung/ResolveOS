Audit: the latest B live result (20261010T230023-live-68e8c5) requests post-timeout confirmation and retry/asynchronous processing evidence as well as internal diagnostics. Native tools can read normalized gateway records, payment/ledger/confirmation sources and timelines. Dedicated service health and cross-transaction tools are unavailable. Only whitelisted payload fields survive snapshots; no internal application diagnostics exist. Supervisor receives source-checked findings and explicitly unverified hypotheses. All specialist outcomes must be COMPLETED for native Supervisor scheduling; missing evidence, unsupported findings, contradictions and truncation still block. Model-selected incomplete results are never upgraded. Read-only queue fencing and global 10-request/120000-token/USD0.15 bounds remain unchanged.

Scenario C: receive settled SGD100 payment, post one matching debit (starting balance1000, ending900), observe confirmation HTTP504 and PENDING acknowledgement. Detect and classify/route the missing-confirmation exception while these are the only records. Only after ROUTE_CASE has completed, ingest actual newly timestamped confirmation-only retry request (202 accepted), acknowledgement receipt (CONFIRMED), retry response (200), and workflow reconciliation observation (RECONCILED). Distinct source record IDs distinguish historical pending from subsequent receipt. No repeat payment/debit, model remediation or root-cause claim is added. Native detection attaches late evidence to the existing exception; the case remains open for review. Bank snapshots are taken after fixture construction, before investigation.

The follow-up fixture events occur and are ingested after detection, using PostgreSQL wall time rather than fabricated past ingestion. Ground truth's predefined semantics do not change; generated source IDs, dataset and hashes are frozen after all fixtures are ingested and before the first model turn. Routing occurs before late acknowledgement, so original Transaction/Technology routing is retained legitimately. No Supervisor task is manually scheduled.
