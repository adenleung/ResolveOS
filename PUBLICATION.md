# Source-only GitHub publication

This branch contains the ResolveOS source, migrations, tests, static fixtures and
documentation. Generated experiment evidence, screenshots, JUnit results and
local history bundles are excluded. The complete local `hardening` branch and
verified project ZIP retain those files unchanged.

Some report links and historical replay/regression tests require the excluded
evidence. Use the complete local project for those checks. New offline benchmark
results can be generated with the documented commands and remain local.

Publication does not establish fresh live-model success or production readiness.
GitHub push protection remains enabled; no detection bypass was requested.
